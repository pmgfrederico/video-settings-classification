Video settings playground

A settings UI derived from rules, not hand-designed. Every setting is classified on a fixed set of facets, and one deterministic engine turns the PC's hardware and the player's choices into what the screen shows. Every page runs the same engine against six sample PCs.

  • Facet explorerEvery setting as a collapsible tree, grouped by the facets you pick. The quickest way to understand the classification.
  • Main menu mockupThe settings screen the rules produce: hardware-aware choices, locked fields, a change ledger and Basic / Advanced / Expert detail levels.
  • Main menu mockup · WinUI 3The same screen as a Windows 11 configurator app, in the Fluent design system, with light and dark themes.
  • Main menu mockup · MotorsportThe same screen in a dark in-game style: translucent panels over a photo, red accent, racing type.
  • In-game mockupThe same rules applied to a running session.
